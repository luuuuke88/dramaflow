# 素材中心、片段与视觉手册对照

更新时间：2026-07-19
基线：ToonFlow 1.1.8 打包版与 `Toonflow-web/src/views/assets/index.vue`、
`views/project/components/projectDialog.vue`
范围：资产中心的五个页签、片段文件、音频资产，以及项目可选择的视觉/导演手册。

## 先说结论

素材中心的主工作流已经在 Flutter 中存在：角色、道具、场景、素材、音频五个
页签均可进入，前三类保留了父子资产、搜索、批量操作和图片任务入口；片段是
本地文件落库，不是视频生成；音频资产也有本地导入与 TTS 两条路径。

“全局画风库”不应作为资产页缺口补进去。当前 ToonFlow 打包前端没有调用
`/artStyle/getArtStyle`、`/artStyle/addArtStyle` 或 `artStyle.vue`；真正可达的是
项目弹窗内的**视觉手册**和**导演手册**。DramaFlow 已在项目弹窗提供同类画廊和
编辑器。`art_style_library.dart` 只有自身和隔离测试引用，属于当前不可达的遗留
扩展，既不能拿它给资产页判绿，也不应为了“看起来更丰富”强行放进素材中心。

当前行仍是“部分实现”：本地片段的引擎落盘和列表呈现都有证据，但用户从素材页
点“新增素材”后，经系统文件选择器选文件、保存并看到新行的完整 UI 回归尚未
建立。这是本地媒体文件流，不会也不需要提交、轮询或生成视频。

## 验证记录

已在 Flutter 项目根目录执行：

```bash
flutter test \
  test/widgets/assets_mobile_screen_test.dart \
  test/widgets/assets_tts_screen_test.dart \
  test/widgets/batch_generation_dialog_test.dart \
  test/engine/assets_test.dart \
  test/engine/art_style_test.dart
```

结果：`44` 条通过。覆盖范围包括移动端角色/道具/场景 CRUD、子资产展开、短屏
滚动、平板工具栏、图片和音频预览、音频表单与本地拖入、批量生成参数入队、
片段字节落盘及 `.mp4` 播放缩略图。

该组测试没有发起图像、文本、TTS 或视频供应商请求。`.mp4` 用例只写入临时的
四字节占位文件，用于验证媒体类型分支；没有提交、轮询、下载、渲染或播放视频。

## 后续证据门

1. 为“新增素材”补一条可控文件选择器的 UI 回归：选择一个临时 PNG，保存后断言
   资产行、媒体文件和列表刷新。它只验证本地文件流程，不生成视频。
2. 在 macOS 与 iOS/Android 真机终验收中各走一次系统文件选择器，确认权限、取消
   选择和长文件名展示；不把 widget 夹具冒充为真机文件系统证据。
3. 图像批量生成、TTS 和视频生成的真实供应商质量/额度/时延由用户最终验收；本页
   不越过“视频不做真实生成测试”的边界。
