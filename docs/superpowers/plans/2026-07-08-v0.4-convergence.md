```dart
enum PlacementMode { splitOverlap, ripple, clamp }

class ClipPlacement {
  final int clipId;      // 已存在的 clip；插入新 clip 时先 INSERT 再传 id
  final int? startMs;    // null=不动
  final int? durationMs; // null=不动
  final int? lane;       // null=不动
  const ClipPlacement({required this.clipId, this.startMs, this.durationMs, this.lane});
}

/// 唯一落库核心：一次快照 → 组内净位移一次计算 → splitOverlap 让位（排除组内成员）
/// → 每 lane 一条批量位移 UPDATE。返回新产生的 clip id（分割尾段）。
List<int> _placeClips({
  required int scriptId,
  required List<ClipPlacement> placements,
  required PlacementMode mode,
});
```

核心算法约束（修复 spec §5 前两个 bug 的根）：
1. 快照该 script 全部 clips 一次（`SELECT * FROM o_timelineClip WHERE scriptId=? ORDER BY lane,startMs,id`），后续计算全在内存。
2. ripple 位移：按 lane 分组，**每 lane 只计算一次净位移**（组内该 lane 最大 endMs 变化量），杜绝逐 clip 累加（旧 resizeTimelineClipsEndRipple 的重复累加 bug）。
3. splitOverlap：检测目标区间与**非组内成员**的重叠（组内成员互相排除——旧批量互撞 bug 的修法），跨中点者分割（沿用旧单个版的 head/tail 算式，搬进核心）。
4. 组内成员间最终位置互不重叠校验：违反则按 startMs 顺序顺次后移（保持相对顺序）。
5. 落库：每 lane 一条 `UPDATE ... WHERE id IN (...)` 批量写（顺带消灭 82a2839 N+1）。
