# 画风参考图提示词提取复刻设计

日期：2026-07-21

范围：`W7E-ARTSTYLE-EXTRACT-001`。对齐 ToonFlow
`artStyle/extractStylePrompt.ts` 的“选一至多张参考图，调用视觉模型，回填一个可编辑画风提示词”工作流。

## 目标与边界

用户在画风库新增或编辑画风时，可选择当前表单中的一至多张参考图，点击“提取画风”，把视觉模型
返回的综合画风词填入提示词输入框。用户仍须自行确认并保存画风条目；提取不会新增、修改或删除
数据库记录，也不会生成图片、视频或音频。

这不是项目级视觉/导演手册选择器的替代，也不改变现有封面上传、画风 CRUD 或提示词解析。

## 原版行为

ToonFlow 接收图片数组，调用 `universalAi` 的视觉理解能力；系统指令要求仅输出一个括号包裹、含中文
与英文描述并带“画风”字样的简洁提示词。多图取共同风格；无法描述时允许返回“无法描述”。路由只把
文本结果交回前端，不自行保存画风条目。

## DramaFlow 设计

### 引擎

在 `art_style.dart` 增加一个异步、无持久化 API：

```dart
Future<String> extractArtStylePrompt(List<String> imagePaths)
```

- 只接受一至八个由 `MediaStore` 验证为应用自有常规图片文件的相对路径；空列表、越界路径、非图片
  或不存在文件在调用模型前以现有本地化错误失败。
- 读取图片为 data URL，通过已有 `ProviderGateway` 的视觉文本能力发送一个请求。请求使用当前有效的
  文本/视觉绑定，不新增供应商、密钥字段、模型配置或网络协议。
- 指令复刻原版输出契约：多图综合、仅输出括号包裹的中英画风词。结果去除思考标签和首尾空白；空结果
  作为格式错误，不覆盖编辑器内容。
- API 不写 `o_artStyle`、不落任务、无重试循环；花费确认由 UI 在调用前走既有 `pipeline_policy` 的
  视觉/文本花费确认语义。

### 界面

`_ArtStyleEditor` 使用已有封面选择结果作为首个参考，并提供“添加参考图”和“提取画风”操作：

- 桌面与 `<840dp` 复用同一个编辑器；参考图以可删除缩略图列展示，按钮始终可点击，不依赖 hover。
- 提取进行时禁用提取与保存动作、显示局部进度；失败显示本地化错误并保留用户原有提示词。
- 成功后只替换提示词文本框，用户可以继续修改；“保存”仍是唯一写入画风库的动作。
- 没有已选参考图时不发请求，并显示明确提示。

## 验证

- 引擎 fake gateway 测试：单图、多图 data URL 顺序、指令契约、空/越界/非图片拒绝、无数据库写入、
  空模型输出拒绝。
- widget 测试：1200dp 和 390dp 选择参考、花费确认、加载、成功回填、失败不覆盖、保存前不落库。
- 不调用真实文字、图片、音频或视频供应商；视频生成代码与测试均不触发。

## 非目标

不做自动保存、批量提取、风格图库反向搜索、项目手册迁移、Agent 向量记忆、供应商适配器代码或
真实供应商验收。这些均由各自的总清单行跟踪。
