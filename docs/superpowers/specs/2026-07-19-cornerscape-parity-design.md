# 塑角造景页面等价设计

## 目标

将 DramaFlow 的 `cornerScape` 从仅角色配音绑定的降级页，恢复为与 ToonFlow 1.1.8 `views/cornerScape/index.vue` 行为等价的资产参考图工作台，同时保留并泛化已存在的音频绑定和 AI 批量匹配。实现必须在 macOS 桌面和 390dp 触控宽度下可完成关键操作。

本设计仅覆盖本地状态和供应商任务边界：图片任务可入队、轮询、失败、取消和恢复，但不会在开发或自动化中调用真实图像、文本、语音或视频服务。

## 原版范围

原版页面按角色、场景、道具显示资产卡片，并在一处完成以下工作：

- 按资产类型过滤，勾选任意可见卡片；全选、提示词为空、未生成、已完成、失败、反选、清空与批量预览。
- 选择图像模型、1K/2K/4K、补充提示词后，对选中资产批量生成提示词或图片；生成中的卡片可取消。
- 打开非生成中的资产卡片，在侧栏中查看候选历史图、切换当前图、编辑提示词、选择模型和分辨率、AI 润色并重新生成。
- 在同一资产详情管理该资产关联的音频，左侧还可对选中资产批量 AI 匹配音频。原版后端虽把关联表命名为 `o_assetsRole2Audio`，却没有角色类型过滤：角色、场景、道具都会走该路径。

## 方案

采用“恢复原页面工作台，复用既有引擎能力”的方式：不把批量生图继续藏在资产中心，也不新建第二套队列、图像数据或音频关系。

`CornerScapeScreen` 拆为三个职责明确的私有 UI 单元：批量设置面板、资产卡片网格、资产详情面板。它们只读取 `Engine` 已有的资产、图片历史、任务和音频绑定接口；图像生成继续使用 `generateAssetImages`，提示词润色继续使用既有资产流水线，取消继续走统一 `cancelJob`。详情面板选择历史图时调用现有 `saveAssetImage`，不改数据库 schema。

现有角色音频 API 不会删除：它成为通用资产音频 API 的角色筛选兼容包装。通用 API 继续复用既有 `o_assetsRole2Audio` 表，不做 schema 迁移；详情面板和批量匹配允许角色、场景、道具使用同一条关联路径，符合原版 `getAllAssets.ts`、`batchBindAudio.ts` 和 `updateAssetsAudio.ts` 的实际类型语义。

## 数据与状态

页面本地状态仅包含：类型筛选集合、可见资产 id 的选中集合、模型、分辨率、补充提示词、当前详情资产 id 和预览图片 id。列表每次由 `Engine.getAssets` / `assetImages` 重新派生；任务变更由既有 `jobsGenerationProvider` 刷新。

快捷选择的判定与原版保持一致：

| 动作 | 条件 |
| --- | --- |
| 未生成 | 当前资产没有选中图片或图状态为空 |
| 已完成 | 当前选中图片状态为完成 |
| 失败 | 当前选中图片状态为失败 |
| 提示词为空 | `prompt == null` 或去首尾空白后为空 |
| 批量预览 | 优先预览已选且有本地图的资产；没有选中则预览可见的全部本地图 |

取消只对当前生成任务对应的任务行生效。若未找到可取消任务，显示“当前没有可取消的生成”，不创建新任务或修改已有图状态。

## 跨端 UI

桌面采用“设置栏 + 自适应卡片网格”，资产详情用右侧抽屉式面板；窄屏将设置区、批量操作和卡片列表按纵向排列，资产详情使用全屏自适应表单。卡片上的选择、取消、预览、详情入口都必须触控可达，不能依赖 hover。

图片预览使用现有本地媒体预览组件；缺图、生成中、失败均有稳定高度的占位状态。长资产名截断，不扩大卡片或压坏操作按钮。

## 验收与边界

- 每一项新增行为先写 widget/engine 失败测试；桌面与 390dp 至少各覆盖一次真实入口。
- 通过 fake gateway、内存 SQLite 与临时媒体文件验证批量任务 payload、状态筛选、取消、历史图切换、提示词保存、角色音频操作。
- 不调用真实模型，不测试视频生成；视频相关代码不改动。
- 完成后更新 `docs/parity/master-checklist.md` 的 `W6-CORNERSCAPE-002`，并在 `feature-parity-execution-report.md` 写出能力、证据和仍需用户亲手做的真实供应商体验验收。

## 明确不做

- 不复制 Electron/axios/轮询实现，也不重新设计数据库或队列。
- 不新建独立“角色情景图片”数据模型，也不新建音频关联表；原有 `o_assetsRole2Audio` 仅是历史命名，作为通用资产关联表继续使用。
- 不在本期补视频生成、自由时间线或 Agent 系统。
