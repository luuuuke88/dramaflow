# 制作画布首次操作引导设计

## 目的

补齐 ToonFlow 1.1.8 制作画布的首次操作引导。它是项目内的局部教学，和全局首次启动欢迎页
无关，不读取供应商、不调用模型、更不触发视频生成。

## 基线与范围

原版 `Toonflow-web/src/views/production/index.vue:97,463-489` 使用本地
`productionCurrent` 保存进度，依次说明：切换剧集、刷新数据、自动布局、画布导航。完成后
该浏览器不再重复显示。

DramaFlow 使用本地 SQLite `o_setting`，新增唯一设置键 `production.guide.completed`：默认 `0`，
用户跳过或完成后写为 `1`。它和 `onboarding.completed` 一样是设备级状态，清空项目内容时不重置，
不进入配置导出，也不存储任何密钥。

## 交互设计

### 桌面

画布已有足够的真实控件，不新增教程框架或第三方依赖。

1. 选集：高亮剧集选择条，解释剧集决定当前画布的脚本、分镜和工作台数据。
2. 刷新：新增一个紧凑的刷新图标按钮，重新构建当前制作视图以读取本地引擎的最新数据；内嵌
   引擎没有 HTTP 缓存，但这是用户可见的刷新动作，不是假按钮。
3. 自动布局：高亮既有自动布局按钮，恢复六节点默认链路，并把视口重新对齐节点区域。
4. 画布：高亮画布，说明拖拽空白处平移、滚轮/触控板缩放、拖动节点标题栏移动节点。

引导遮罩只在当前步骤高亮控件，说明卡片邻近目标且不会超出窗口；按 Escape、跳过或最后一步
完成都会持久化完成状态。卡片有上一步/下一步、进度、语义标签和键盘可达按钮。

### 390dp 及其他窄屏

窄屏不使用无限画布，而是现有六 Tab。引导仍为同一四个概念，但以全屏步骤面板呈现：剧集、
刷新、节点检查器/自动布局替代说明、Tab 导航与全屏 Agent 入口。每一步都可完整阅读和操作，
不把桌面悬浮卡缩到不可点击。

## 组件边界

新增 `production_guide.dart`，仅负责引导的步骤状态、遮罩、目标定位和响应式展示；它不知道项目、
供应商、Agent 或视频。`ProductionScreen` 持有一次性的显示状态、为真实控件提供 GlobalKey，
并在结束时通过 `EngineConfig` 写完成标记。`DFCanvas` 暴露一个可选 controller，使“自动布局”在
复位节点后可以对当前视口执行真实 fit，不在引导组件内修改画布状态。

## 验收

- 新数据库首次打开带剧本的制作页会显示第 1/4 步；无剧本时不显示。
- 桌面四步依次定位到剧集、刷新、自动布局、画布；完成/跳过后同一数据库重进不再显示。
- 点击刷新会重新构建当前画布；自动布局同时复位节点并重新居中视口。
- 390dp 显示四步全屏引导，所有按钮可见、可完成并持久化。
- 中文、英文、日文文案齐全；测试只用内存数据库和假网关，不调用文本、图片、音频或视频模型。

## 非目标

- 不增加设置页“再次播放教程”入口，原版没有。
- 不复刻浏览器 `localStorage` 或 Vue 的 `t-guide` 实现细节。
- 不把此功能扩展为视频教程、动画演示或实时性能检测。
