## 1. 不变的底座（v0.2 已验证，禁止回退）

1. 单体 Flutter 多端 App（macOS 验收优先；win/android/ios/web 响应式保持）。
2. Dart 内嵌引擎 `app/lib/src/engine/`：sqlite3 直用、dio、事件广播 JobQueue（text/image/video 三 lane 串行）、MediaStore 本地媒体。
3. **零 ffmpeg 合成定案**：macOS/iOS=AVFoundation（`dramaflow/composer` MethodChannel）；Android=Media3 Transformer；Web=WebCodecs+Mediabunny。永不依赖用户本机 ffmpeg。ToonFlow 前端用 WebAV（WebCodecs）合成，反向验证了本定案。
4. 供应商可插拔层：协议适配器（openai_compatible/volcengine）+ DB 实例 + 阶段绑定 + resolve 校验。
5. 任务落库、错误中文可见、可重试、冷启动恢复。**Agent 体系也必须跑在这套队列上**——这是对治 ToonFlow「报错不可见」的底线，不许绕开。
6. Codex 协作流水线：Claude 写规格/审核/亲自验证/提交；`codex exec --full-auto` 执行；analyze 零告警 + 测试全绿为合入门槛。
7. 硬约束重申：不依赖本机 ffmpeg；Flutter Web H5 最终要跑完整流程；未来上架 App Store（许可证干净——抄的是产品形态与流程，Flutter 代码全部重写，不复制 Vue/Node 源码）。

## 4. Agent 体系设计（照抄形态，保住可见性）

ToonFlow 的 Agent = 每个生成阶段一个 LLM 执行器（模型+提示词+技能集+执行模式 auto/manual）+ 制作画布右侧对话框。Dart 引擎实现同构 **agent loop**：

1. `engine/agents/`：AgentRunner（LLM tool-calling 循环）+ 内置技能集（与 ToonFlow `o_skillList` 出厂技能对齐：章节解析/事件提取/剧本生成/资产提取/分镜生成等——本质是把 v0.2 的 runners 重组为可配置技能）。
2. 每次 agent 执行落 `o_tasks`，错误中文可见、可重试、可取消——**不许出现"对话框里失败但任务表里查无此事"**。
3. 执行模式：auto（导演自动连跑语义并入）/ manual（分步按钮）双模式，项目级 `mode` 字段控制，与 ToonFlow 一致。
4. rightChatBox：对话消息落库（o_agentWorkData），对话中触发的生成动作 = 排队任务，进度在对话框和任务中心双向可见。
5. 自定义 JS 技能：用 flutter_js（QuickJS）执行，排 P5；若跨端验证不过，降级为「查看+参数编辑」并在页面明示"自定义技能执行暂不可用"，不做无声阉割。

## 5. UI 设计系统（先定系统，后写页面）

1. P1 开工前用 **frontend-design skill** 产出设计系统落稿：色板（浅色为主+暗色）、字阶、间距、圆角阴影、表格规范、卡片规范、状态徽章、空态插画、骨架屏、微交互（hover/按压/过渡）——落成 `app/lib/src/theme/` 的 ThemeExtension 常量与通用组件库 `widgets/`，所有页面只准从这里取样式。
2. 布局密度、信息架构、操作路径照抄 ToonFlow；视觉目标：明显比 antd 默认风格精致。
3. 每批合入前的审核项加一条：截图对照 ToonFlow 同页，布局对应、观感更优才算过。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 无限画布性能（Flutter 自绘） | P3 首任务先做 spike：InteractiveViewer+CustomPainter 基准测试，不达标换 flame/自研分层渲染，spike 结论回写本文档 |
| 多轨时间线复杂度 | 照抄 ToonFlow 的 track 数据结构，UI 分两步：先只读时间线+版本挑选，后拖拽编辑 |
| 富文本剧本编辑器 | 优先 super_editor / flutter_quill 评估，以「格式高亮+稳定中文输入」为准入 |
| docx 导入 | Dart 端 docx→文本解析（docx 为 zip+xml，可控），失败则先支持 txt 并页面明示 |
| flutter_js 跨端 | 排 P5 且有明示降级路径（见 §4.5） |
| TTS 供应商 | volcengine TTS 协议适配器（vendor 层新 kind），真声验收留 luke |
| 工程量 | 全部走 Codex 流水线并行分发；每批可用是硬门槛，宁可批内砍页数不许半成品合入 |
