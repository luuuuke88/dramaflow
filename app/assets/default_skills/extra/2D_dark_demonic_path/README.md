# 黑暗魔道风格说明

本风格专为"暗黑系仙侠"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **暗黑系仙侠二次元**：以修真世界的反面为背景的二次元厚涂风格，涵盖魔道、入魔、堕落、复仇等题材
- **低键光美学**：墨黑占据画面主体，光只作为切割暗部的工具，高光面积极小且边缘锐利
- **二次元厚涂技法**：厚涂笔触、硬边阴影、明确的明暗交界线，介于赛璐璐与写实之间
- **克制的暖色**：全片唯一的暖色来源是血、火与魔丹，一旦出现即为强烈的叙事信号
- **腐朽质感**：破败宗器、锈蚀金饰、干涸血迹、朽木残碑，一切材质都带着时间与暴力的痕迹
- **戏剧化黑暗**：追求压迫感与堕落的美感，不做生理性猎奇

## 适用范围

- 魔道/入魔/复仇/双主角对立题材的 AI 美术生成
- 需要压抑氛围、高对比光影、诡谲色调的视觉创作
- 可与「国漫修仙3D」「国风二次元」等正道风格搭配，用于表现阵营对立

## 严禁内容

- 明亮通透的高调画面/阳光暖调/清新氛围
- 仙青、金光等正道系灵光色
- 照片级真人摄影/3D 写实渲染
- 西方哥特十字架/吸血鬼/恶魔角等欧美暗黑符号
- 血腥器官特写/断肢内脏等生理性猎奇画面
- 健康红润肤色/柔和大面积高光
- 赛博朋克霓虹/机械科技元素

## 内容尺度

本风格表现的是**戏剧化的黑暗美学**，不是猎奇与恐怖。血只以渗染、血雾、血泊、血污的形式出现；死亡以剪影、白骨、残破衣物暗示；痛苦靠表情、体态与氛围烘托。禁止断肢、内脏、器官特写与伤口解剖细节，禁止自残与虐待过程的具体描绘。

## 风格体验

在本风格下，您将体验到：

- 角色苍白清瘦、眼下带青、魔纹沿颈侧攀爬，衣袍曳地且边缘破损
- 场景常年不见天日，光从铁栅、裂隙、鬼火中漏进来，把画面切成明暗条块
- 法宝锈蚀带血槽，符文是暗红而非金色，材质腐朽感强烈
- 分镜强调低键光、硬边阴影与压迫构图，用画面而非台词传达失控与堕落
