# 黑暗魔道约束 · 暗黑系仙侠二次元 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：墨黑（C1 #121016）、血赤（C2 #8E1B24）、幽紫（C3 #4B2E63）、冷白（C4 #D9DDE2）、锈金（C5 #8A7038）、铁灰（C6 #3A3D44）、病青（C7 #5C7A6E）、暗褐（C8 #4A342A）、惨绿（C9 #6E8C3A）、灰蓝（C10 #56606E），整体色温极冷（6500-7800K），饱和度低（25-45%），呈现压抑阴森的魔道基调
- **暖色是稀缺资源** — 全片唯一的暖色来源是血、火与魔丹，必须落在 C2 血赤色域。暖色出现频率越低，每次出现时的叙事分量越重。禁止阳光暖调
- **冷暖分配策略** — 日常与潜行段落用纯冷调（墨黑 + 铁灰 + 灰蓝）；杀戮与入魔段落引入血赤；鬼域与毒计段落用病青与惨绿；魔宗正殿用锈金体现腐朽的秩序
- **色盘先行原则** — 段落规划需先绑定情绪场景（堕落入魔/魔宗议事/屠戮修罗/尸山鬼域/囚牢反噬/雪夜独行），再确定主色+辅色与光影方案，避免"剧情黑了但画面没黑"
- **明度即处境** — 角色处境越绝望，画面平均明度越低、暗部占比越高。转折与解脱瞬间可短暂提亮，但不得超过全片 10% 的时长
- **禁用色域** — 明亮通透的高调画面、仙青与金光等正道灵光色、赛博霓虹均与本风格不兼容。色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±10%（暗部从严）

## 二、光影方案体系

- **光影即处境** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **低键光为锚** — 所有光影方案必须保持墨黑占画面 50% 以上，阴影边缘锐利，高光面积极小。暗部必须保留细节，禁止糊成死黑
- **光源角度** — 默认单一光源，来自侧下方（血光/火光上打）或高处铁窗（条状光）；正面平光仅用于表现"被审视"的压迫感

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 血光上打 | 墨黑 + 血赤，底部光源 | 堕落入魔、痛苦蜕变、失控 |
| B | 铁窗光条 | 铁灰 + 墨黑，条状硬光切割 | 囚牢、束缚、审判、压迫 |
| C | 火把孤光 | 墨黑 + 暗橙火光，单点 | 潜行、密谈、暂时的安全 |
| D | 鬼火惨绿 | 惨绿 + 病青，飘忽无定 | 尸山鬼域、诡谲、非人 |
| E | 幽紫魔气 | 幽紫 + 墨黑，边缘畸变 | 魔功运转、异变、不可名状 |
| F | 血月天光 | 血赤漫射 + 墨黑 | 屠戮高潮、命运降临、宿命 |
| G | 雪夜极简 | 冷白 + 灰蓝，极低对比 | 孤绝、寂灭、疲惫、收尾 |

- **冷暖光分配** — 除方案 A、C、F 外一律冷光。方案 C 的火光是全片唯一"温暖"的段落用光，应留给人物关系的短暂缓和
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **二次元厚涂为锚** — 本风格的核心：厚涂笔触、明确的明暗交界线、硬边阴影，介于赛璐璐与写实之间，禁止 3D 写实与照片质感
- **哑光为主，高光为刃** — 皮肤与布料以哑光呈现，高光只出现在鼻梁、颧骨、刃口、锁链这些需要"扎眼"的地方，面积极小、边缘锐利
- **材质腐化** — 所有服化道必须体现腐朽：金属锈蚀沉积、布料发脆卷边、纸张泛黄透血、木材霉变。全新无瑕 = 风格失败
- **皮肤质感** — 冷白偏灰、无血色、颈侧血管隐现、眼下淡青黑。禁止健康红润与大面积柔和高光
- **黑不等于糊** — 墨黑占主体不意味着看不清。暗部必须有层次：黑袍要有明暗交界线，黑石要有纹理，黑雾要有体积

---

## 四、魔道场景空间元素

暗黑仙侠世界观特有的场景元素及其视觉叙事功能：

- **铁栅栏/锁链/立柱** — 天然的画面切割工具，把角色关进条状光影里，视觉上先于台词说出"他被困住了"
- **黑雾/瘴气/血雾** — 空间分隔与情绪浓度计，雾越浓角色处境越危险；也是遮蔽血腥细节的天然手段
- **断裂宗徽/倾倒神像/被划破的匾额** — 承载"背叛与决裂"的符号，用于闪回与身份转折段落
- **鬼火/火把/魔丹** — 暗场景中唯一的光源载体，鬼火 = 非人（方案D）、火把 = 人间（方案C）、魔丹 = 诱惑（方案A）
- **血泊/血渍/干涸血迹** — 时间标记：鲜红 = 刚刚发生，暗褐 = 已过去很久
- **段落间用空镜过渡** — 建议用滴水的石壁、摇曳的鬼火、翻涌的黑雾做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（火把熄灭、魔纹爬上脸颊、宗徽落地断裂）而非依赖对白解释
- **暗部留白** — 大面积暗部本身就是构图元素，敢于让画面 60% 是黑的，把观众的注意力逼到那一点光上

## 五、魔道乐器与环境音

暗黑仙侠世界观下的声音元素约束：

### 乐器选择

- **骨笛/低音埙** — 阴森、非人、诡谲段落的核心乐器，音色越干越好
- **低音大提琴（拨弦）** — 潜行与压迫段落的心跳替代物，单音重复即可制造焦虑
- **失谐古琴** — 故意走音的古琴，用于表现"正道已崩坏"，是本风格的标志性音色
- **金属刮擦/铁链拖曳** — 半乐器半音效，用于囚牢与刑罚段落
- **战鼓（闷鼓）** — 屠戮段落的节奏引擎，鼓皮闷而不亮，区别于正道的清脆战鼓
- **人声气声（无词）** — 入魔与反噬时的终极手段，用气声与喉音而非清亮吟唱，一部剧不宜超过两次
- **静默** — 最强的手段。屠戮高潮处突然抽掉所有配乐，只留环境音，比任何配乐都狠

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 开场/定调 | 失谐古琴独奏 |
| 潜行/压迫 | 低音大提琴拨弦 + 极弱环境音 |
| 囚牢/束缚 | 铁链拖曳 + 金属刮擦 + 低频嗡鸣 |
| 鬼域/诡谲 | 骨笛 + 不规则打击 |
| 入魔/异变 | 人声气声 + 幽紫音色合成音 + 失谐弦乐 |
| 屠戮高潮 | 闷鼓密集 → 突然全静默 |
| 孤绝/收尾 | 低音埙独奏，或纯风声 |

### 魔道环境音

- **典型环境音层次** — 石壁滴水 / 铁链拖曳 / 乌鸦啼叫 / 黑雾流动的低频嗡鸣 / 火把噼啪 / 骨骼相碰的轻响 / 布料曳地摩擦 / 远处不明的闷响
- **每场戏标注 1-2 个核心环境音**。魔道世界的"寂静"极重要：囚牢与雪夜段落应大胆使用近乎无声，只留一两个细微环境音，让观众自己不安
