# 分镜表黑暗魔道约束 · 暗黑系仙侠二次元 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供暗黑系仙侠二次元风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **低键光统一** — 一场戏内墨黑必须持续占画面 50% 以上，除非有明确的叙事转折（如火把熄灭→鬼火亮起）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（堕落入魔/魔宗议事/屠戮修罗/尸山鬼域/囚牢反噬/雪夜独行），并在镜头组内保持主色+辅色连续性，色彩取自核心色盘（墨黑 #121016 / 血赤 #8E1B24 / 幽紫 #4B2E63 / 冷白 #D9DDE2 / 锈金 #8A7038 / 铁灰 #3A3D44 / 病青 #5C7A6E / 暗褐 #4A342A / 惨绿 #6E8C3A / 灰蓝 #56606E）
- **光源角度规范** — 默认单一光源，来自侧下方（血光/火光上打）或高处铁窗（条状硬光）；正面平光仅用于表现"被审视"。描述光影时须写明光源方位、形状与是否切割画面
- **冷暖色调与叙事阶段匹配** — 除堕落入魔、密谈、屠戮高潮外一律冷光；暖色必须来自血、火或魔丹，禁止阳光暖调
- **魔纹即人物状态灯** — 角色魔纹面积与眼瞳状态必须与其当前入魔程度严格一致，同一场戏内不得无故忽强忽弱。魔纹变化点必须在分镜表中标注
- **暗部保留细节** — 墨黑占主体不等于看不清，黑袍要有明暗交界线、黑石要有纹理、黑雾要有体积。分镜表中若标注大面积暗部，须同时标注该暗部里保留哪一处可读信息
- **光影转场是高级手段** — 从火把孤光渐变到鬼火惨绿 = 人间坠入非人。在分镜表中标注光影变化点

---

## 三、环境动态

- **环境动态增加画面呼吸感** — 黑雾贴地流动、火把跳动、锁链轻晃、血滴坠落、雪粒斜掠。每 3-4 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **魔道环境元素优先** — 环境动态应选用暗黑仙侠世界观内的元素：黑雾、瘴气、鬼火、血滴、乌鸦、飘落的符纸灰烬，禁止出现现代或机械元素
- **厚涂动态质感** — 环境动态元素必须保持二次元厚涂质感与硬边阴影，禁止 3D 粒子特效与写实流体
- **动态即遮蔽** — 黑雾与血雾同时承担"遮蔽血腥细节"的功能，需要暗示暴力时优先用雾遮挡而非直接呈现

---

## 四、魔道动作节奏

- **动作两极化** — 默认极静（近乎不动），爆发时极快（3-5 帧完成）。中间速度是本风格最忌讳的，会削弱压迫感
- **曳地黑袍是核心画面资产** — 广袖、下摆、腰带的拖曳与翻卷是天然的动态资产，可在画面描述中加入衣袍动态，须体现厚重感与惯性，禁止轻飘飘的丝绸感
- **仪态约束** — 魔道人物的举止应体现失控边缘：过分静止或过分张扬，缺乏中间态；不出现现代化肢体语言（如耸肩、摊手）。入魔越深，动作越不符合人类习惯（如头部角度偏移过大、关节反向停顿）
- **头身比一致** — 动作设计中角色必须保持 7-8 头身的清瘦比例，禁止因动态姿势而破坏头身比
- **暴力的表现方式** — 杀戮镜头一律用剪影、血雾、光影骤变、旁物反应（溅上墙的血、倒下的烛台）来表现，**禁止**直接呈现创口、断肢与内脏

---

## 五、材质与质感约束

- **二次元厚涂为锚** — 所有镜头中人物/服饰/道具/场景的渲染必须保持厚涂质感与硬边阴影，禁止 3D 写实/照片级渲染/赛璐璐平涂
- **皮肤材质** — 冷白偏灰、无血色、哑光、极小锐利高光、眼下淡青黑，禁止健康红润与大面积柔光
- **服饰材质** — 厚重布料、下摆磨损撕口、边缘卷曲发脆，禁止轻飘丝绸感与全新无瑕
- **道具材质** — 金属锈蚀沉积、黑玉哑光内透幽紫、骨材细孔微黄，禁止镜面反射
- **场景材质** — 石面霉斑、铁锈流痕、干涸血渍、墙面剥落，材质腐朽感强烈

---

## 六、色彩约束

- **核心色盘锁定** — 分镜表中所有镜头的色彩必须取自核心色盘（C1-C10），色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±10%
- **禁止正道光色** — 严禁仙青、金光等正道系灵光色出现
- **魔光颜色** — 血赤为常态，幽紫用于魔功与异变，惨绿用于鬼域，禁止色盘外颜色
- **暗部色** — 墨黑或铁灰，须保留细节，禁止糊成死黑
- **整体色温** — 极冷 6500-7800K，对比度 70-90%，饱和度 25-45%（血赤可局部破例至 60%）

---

## 七、运镜禁忌

- **禁用轻快运镜** — 明快的横移、上扬的升镜与本风格的压抑气质冲突
- **禁用花式转场** — 划屏、旋转、百叶窗等与本风格不兼容，段落衔接优先用黑雾或空镜
- **慎用手持晃动** — 仅在失控与反噬段落使用，且不超过 3 个镜头，滥用会变成廉价恐怖片
- **压迫感优先** — 多用微仰角、前景遮挡（栅栏/立柱/垂幡）、画面边缘压暗，让观众"从缝里看"
- **静止镜头是武器** — 长时间不动的固定镜头配合环境音，比任何运镜都更让人不安，建议每场戏至少留一个
