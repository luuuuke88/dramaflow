# 场景衍生资产生成 · 约束手册

> 衍生场景 = 在「基础场景」之上更换时间、天候、季节、战损或魔气浓度的变体。
> 空间结构、建筑形制、材质体系**永不改变**，仅改变光照与附着状态。

---

## 一、衍生原则

1. **空间不可动** — 建筑位置、体量、结构、材质必须与基础场景完全一致
2. **只改状态** — 时间/天候/魔气/损毁为附加层
3. **光照重算** — 时间与光源变化后，光条方向、色温、阴影必须整体重算
4. **痕迹累加** — 血污与破损只增不减

---

## 二、时间变体

| 时段 | 光源方向 | 色温 | 主色 | 提示词 |
|---|---|---|---|---|
| 阴昼 | 无方向漫射 | 7000K 冷 | 铁灰 + 墨黑 | 阴云漫射弱光、无投影方向 |
| 黄昏 | 低角度侧光 | 4200K 微暖 | 锈金 + 墨黑 | 低角度锈金余光、长而硬的投影 |
| 入夜 | 单点人工光 | 3000K（火）/ 7500K（鬼火） | 墨黑 + 血赤 或 惨绿 | 火把孤光 / 鬼火惨绿、大面积暗部 |
| 深夜 | 冷月或无光 | 8000K 极冷 | 墨黑 + 灰蓝 | 极弱冷月、近乎全暗、剪影为主 |
| 血月 | 天顶暗红漫射 | 特殊 | 血赤 + 墨黑 | 血月天光、全场泛红、不祥 |

---

## 三、天候变体

| 天候 | 视觉表现 | 提示词 |
|---|---|---|
| 阴云 | 厚重压顶、无直射光 | 阴云压顶、漫射弱光 |
| 黑雾涌动 | 有体积、吞噬远景、缓慢流动 | 黑雾翻涌、远景被吞没 |
| 血雨 | 暗红雨丝、地面积水泛红 | 血色雨丝、地面泛红积水 |
| 瘴气 | 病青绿雾贴地流动 | 病青瘴气、贴地流动 |
| 落雪 | 冷白覆盖、反衬黑与血 | 积雪覆盖、黑白血三色对比 |
| 死寂无风 | 一切静止、烟直上 | 无风、烟柱笔直、凝滞感 |

---

## 四、魔气浓度变体

| 状态 | 表现 | 提示词 |
|---|---|---|
| 稀薄 | 基线状态，仅角落有暗影堆积 | 魔气稀薄、角落暗影 |
| 中等 | 空气中可见幽紫微粒，边缘轻微畸变 | 幽紫微粒、边缘轻微畸变 |
| 浓郁 | 黑雾贴地翻涌，物体轮廓被侵蚀 | 黑雾贴地翻涌、轮廓被侵蚀 |
| 沸腾 | 空间扭曲、光线折射异常、血赤爆点 | 空间扭曲、光线异常折射、血赤爆点 |

---

## 五、战损变体

| 程度 | 表现 | 提示词 |
|---|---|---|
| 轻微 | 局部碎石、器物倾倒、灰尘扬起 | 局部碎石、器物倾倒、扬尘 |
| 中度 | 梁柱开裂、墙面刀痕、血迹泼溅 | 梁柱开裂、刀痕纵横、血迹泼溅 |
| 重度 | 大面积废墟、焦痕、血泊、散落骨骸 | 大面积废墟、焦黑痕迹、血泊、散落骨骸 |

> 战损须遵循力学逻辑：坍塌方向、碎块堆积、承重结构失效路径必须合理。
> 血迹只以泼溅、渗染、干涸血泊形式出现，**禁止**出现尸体特写、断肢或内脏。

---

## 六、画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面主视图，与基础场景同机位或近机位 |
| 人物 | **严禁出现任何人物、人影、人体轮廓**（散落白骨不算人物） |
| 一致性 | 建筑位置/体量/结构/材质与基础场景完全一致 |
| 光线 | 按时间与天候整体重算，单一光源逻辑 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 建筑位置/体量/结构/材质必须与基础场景完全一致 |
| R2 | 必须声明时间时段并给出对应的光源方向与色温 |
| R3 | 必须声明天候状态与魔气浓度 |
| R4 | 必须为「单画面主视图」，与基础场景同机位或近机位 |
| R5 | **严禁出现任何人物** |
| R6 | 墨黑必须占画面 50% 以上 |
| R7 | 战损必须遵循力学逻辑 |
| R8 | 血污与破损痕迹只增不减 |
| R9 | 暗部必须保留细节，禁止死黑一片 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 改变基础场景的建筑位置/体量/结构/材质 |
| X2 | 时间与光源方向矛盾 |
| X3 | 天候与季节矛盾 |
| X4 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X5 | 画面被拼接成多视图/网格/分屏布局 |
| X6 | 战损后材质反而变新、痕迹减少 |
| X7 | 明亮通透的高调画面 / 阳光暖调 |
| X8 | 仙青、金光等正道系灵光色 |
| X9 | 尸体特写、断肢、内脏等生理性猎奇内容 |
| X10 | 暗部糊成死黑、无任何细节 |
