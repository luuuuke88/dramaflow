# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **清瘦即气质** — 骨感、清瘦、略显病态是本风格人物的统一底色
2. **底模即基础** — 素色黑袍 + 素颜，魔纹、法宝、战损均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **危险气质** — 无妆状态仍需体现失控边缘的气度（乖张/阴郁/漠然）

---

## 二、面容约束

> 不固定五官参数，由角色描述（性别/年龄/性格/入魔程度）驱动 AI 自由生成五官，保证人物间差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 暗黑系仙侠二次元、二次元厚涂、低键布光、硬边阴影 |
| 面部结构 | 颧骨略突出、脸颊微凹、下颌线清晰，体现清瘦感 |
| 气质 | 必须从角色描述提炼气质关键词（如阴郁乖张/漠然疏离/疯态张扬），并写入提示词 |
| 表情 | 中性微表情，眼神须冷或空，禁止温暖笑意 |
| 眼下 | 统一带淡青黑眼圈，体现耗损感 |

## 六、基础服装约束

> 基础服装为素色黑袍，无魔纹、无配饰。正式服饰在服化衍生环节叠加。

### 女性基础服装

素色黑袍，交领，广袖，衣长曳地，腰束素黑带，无纹样。

### 男性基础服装

素色黑袍，交领，衣长曳地，腰束素黑带，无纹样。

### 着装统一规则

- 黑袍必须有明确的明暗交界线，禁止糊成一团黑
- 除面部/手部/颈部外基本覆盖，露肤面积极小
- 四视图服装款式完全一致
- 基础服装仅为安全打底，焦点在面容与体态的病态感

## 七、四视图设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 头顶至锁骨 | 从头顶到锁骨完整展示，面部占60%+，眼下青黑清晰 | portrait closeup、face detail |
| 左二 | 正视图 | 正面 0° | 全身立像 | 面对镜头、双臂自然、从头顶到脚底完整展示 | front view、full body |
| 右二 | 侧视图 | 右侧 90° | 全身立像 | 纯侧面轮廓清晰、从头顶到脚底完整展示 | side view、profile、full body |
| 右一 | 后视图 | 后方 180° | 全身立像 | 后脑/背部/发尾/脚部清晰、从头顶到脚底完整展示 | back view、rear view、full body |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 铁灰纯色 #3A3D44（设定图为可读性破例，不用纯黑） |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂 |
| 全身展示 | 全身立像必须从头顶到脚底完整入画，严禁裁切 |
| 特写展示 | 人像特写必须从头顶到锁骨完整入画，严禁裁切 |
| 表情 | 中性微表情，眼神冷或空 |
| 光线 | 设定图用途优先可读性：主光偏上前方 45° + 弱侧补光，允许比正片明亮，但仍保持冷调与硬边阴影 |
| 一致性 | 四视图的肤色/体型/发型/面容/基础服装完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（素色黑袍、交领、曳地、腰束素黑带） |
| R3 | 必须声明「无发饰、无魔纹、无配饰」 |
| R4 | 必须指定「铁灰纯色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例（默认 7-8 头身、清瘦修长） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 必须声明「冷白无血色」与「眼下淡青黑」 |
| R10 | 黑袍必须有明确明暗交界线，禁止糊成一团黑 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 基础服装以外的任何服装/魔纹/法宝/配饰/妆容 |
| X2 | 暖色光源（设定图光源必须为冷调） |
| X3 | 健康红润肤色 / 大面积柔和高光 |
| X4 | 复杂场景背景（必须纯色） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底 |
| X7 | 人像特写裁切头顶 |
| X8 | 忽略身高和头身比约束 |
| X9 | 3D 写实渲染 / 照片级真实感 |
| X10 | 西方哥特/吸血鬼/恶魔角等欧美暗黑符号 |
| X11 | 任何血腥伤口、断肢、器官等生理性猎奇内容 |
