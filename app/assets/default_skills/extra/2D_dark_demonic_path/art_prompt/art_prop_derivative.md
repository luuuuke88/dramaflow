# 道具衍生状态生成 · 约束手册

> 衍生道具 = 在「基础道具」之上改变激活状态、损毁程度、封印状态或邪性跃迁的变体。
> 形制、主体材质、纹样布局**永不改变**，仅改变状态附着层。

---

## 一、衍生原则

1. **形制不可动** — 外形轮廓、比例、结构、纹样布局必须与基础道具完全一致
2. **只改状态** — 魔光、损毁、封印、锈蚀程度为附加层
3. **痕迹只增** — 锈蚀与血迹不可回退（除非明确设定为"重炼/祭血"）
4. **质感承续** — 厚涂笔触、硬边阴影、低键布光等质感规则全局继承

---

## 二、激活状态

| 状态 | 表现 | 提示词 |
|---|---|---|
| 沉眠 | 无魔光、纹样如死物、锈色最重 | 无魔光、纹样晦暗、锈色沉重 |
| 苏醒 | 血槽内开始渗出暗红、纹样微亮 | 血槽渗暗红、纹样微亮 |
| 激发 | 魔光明亮、黑雾自表面溢出 | 强魔光、黑雾溢出、边缘畸变 |
| 饱食 | 魔光刺目、空间扭曲、器身微颤 | 刺目魔光、空间扭曲、器身震颤 |

> 魔光颜色须与基础道具的邪性等级色域一致（染器/魔器：C2 血赤或 C3 幽紫；邪宝/遗物：可加血月色异光）。

---

## 三、损毁状态

| 程度 | 表现 | 提示词 |
|---|---|---|
| 微损 | 刃口崩缺、表面划痕、纹样局部断裂 | 刃口崩缺、表面划痕、纹样局部断裂 |
| 中损 | 主体裂纹贯穿、部件缺失、魔光闪烁不稳 | 贯穿裂纹、部件缺失、魔光闪烁不稳 |
| 重损 | 断裂为数段、魔纹失效、魔光尽灭 | 断裂数段、魔纹失效、彻底无魔光 |

> 断口必须符合材质力学：金属为韧性撕裂口，黑玉为脆性贝壳状断口，骨材为纵向劈裂。

---

## 四、封印状态

| 类型 | 表现 | 提示词 |
|---|---|---|
| 符纸镇压 | 表面贴附泛黄符纸，符纸边缘焦卷 | 泛黄符纸镇压、符纸边缘焦卷 |
| 锁链缠绕 | 缠绕锈铁锁链、链身有镇压铭文 | 锈铁锁链缠绕、镇压铭文 |
| 阵法封禁 | 悬于阵纹中央、阵纹暗红发光 | 悬浮阵纹中央、暗红阵纹、束缚感 |
| 深埋封存 | 半埋于土石、覆苔藓与尘 | 半埋土石、苔藓覆盖、厚积尘 |

---

## 五、邪性跃迁

> 仅在剧情明确"祭血/重炼/吞噬"时使用。

| 变化 | 允许的改动 | 禁止的改动 |
|---|---|---|
| 材质腐化 | 表面更粗粝、出现活性起伏 | 更换主体材质种类 |
| 纹样增生 | 在原有纹样基础上向外蔓延新魔纹 | 改变原有纹样布局 |
| 魔光升阶 | 由血赤升为幽紫，或加血月色异光 | 使用色盘外颜色 |
| 尺寸微调 | ±10% 以内 | 明显改变比例或形制 |

---

## 六、画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面单件道具，与基础道具同机位或近机位 |
| 人物 | **严禁出现任何人物、手部或人体局部** |
| 背景 | 墨黑近纯色 #121016 或极简暗背景 |
| 光线 | 单一主光上前方 45°，激活状态可叠加道具自发光 |
| 一致性 | 形制/比例/材质/纹样布局与基础道具完全一致 |
| 画面比例 | 默认 1:1（或按调用方设定） |

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 形制/比例/主体材质/纹样布局必须与基础道具完全一致 |
| R2 | 必须声明激活状态（含"沉眠"） |
| R3 | 魔光颜色必须与基础道具邪性等级色域一致 |
| R4 | 损毁断口必须符合材质力学（金属韧性撕裂/黑玉贝壳状断口/骨材纵向劈裂） |
| R5 | 锈蚀与血迹痕迹只增不减 |
| R6 | **严禁出现任何人物、手部或人体局部** |
| R7 | 必须为单画面单件道具，与基础道具同机位或近机位 |
| R8 | 暗部必须保留细节，禁止死黑一片 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 改变基础道具的形制/比例/主体材质/纹样布局 |
| X2 | 损毁后材质反而变新、痕迹减少 |
| X3 | 断口不符合材质力学 |
| X4 | 仙青、金光等正道系灵光色或色盘外颜色 |
| X5 | 出现人物、手部或任何人体局部 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实渲染/照片级真实感 |
| X8 | 未经剧情设定擅自做邪性跃迁 |
| X9 | 器官、断肢等生理性猎奇内容 |
