# 人物衍生资产生成 · 约束手册

> 衍生资产 = 在「基础形象」之上叠加服化、入魔程度、战损、法宝加持等变体。
> 底模的面容/体型/发色/身高**永不改变**，仅叠加外层。

---

## 一、衍生原则

1. **底模不可动** — 面容、头身比、肤色、发色必须与基础形象完全一致
2. **只做加法** — 服饰、魔纹、法宝、光效为叠加层，不得改写人物本体
3. **入魔可读** — 魔纹面积与眼瞳状态必须能反映角色当前的堕落程度
4. **质感承续** — 厚涂笔触、硬边阴影、哑光肌肤等质感规则全局继承

## 三、入魔程度叠加

| 阶段 | 魔纹面积 | 眼瞳 | 视觉表现 | 提示词 |
|---|---|---|---|---|
| 未入魔 | 无 | 正常黑瞳 | 仅气质阴郁 | 无魔纹、黑瞳 |
| 初染 | 颈侧一小片 | 瞳色略深 | 魔纹暗红、静止不动 | 颈侧暗红魔纹、瞳色转深 |
| 半入 | 颈侧至半边脸 | 单眼幽紫异瞳 | 魔纹缓慢流动 | 半脸魔纹流动、单眼幽紫异瞳 |
| 深陷 | 面部至手背 | 双眼幽紫 | 魔纹发光、发梢挑暗红 | 大面积发光魔纹、双眼幽紫、发梢暗红 |
| 失控 | 全身可见处 | 瞳孔消失，眼白幽紫 | 黑雾自体表溢出，血赤爆点 | 全身魔纹、眼白幽紫、黑雾溢出 |

> 魔纹只做**叠加**，不得改变人物骨相与五官轮廓。魔纹颜色必须落在 C2 血赤或 C3 幽紫色域。

## 四、战损状态

| 程度 | 表现 | 提示词 |
|---|---|---|
| 轻微 | 衣角撕裂、发丝散乱、面颊蹭灰 | 衣角撕裂、发丝散乱、面颊蹭灰 |
| 中度 | 袍身破口、血迹渗染布料、护甲开裂 | 袍身破口、血迹渗染、护甲开裂 |
| 重度 | 大面积破损、血污成片、单膝支地力竭 | 大面积破损、血污成片、力竭姿态 |

> 战损不得改变角色骨相与五官。血污须落在 C2 血赤或 C8 暗褐（干涸）色域。
> **禁止**表现伤口本身：不出现开放性创口、断肢、内脏，只以衣物破损与血迹渗染暗示。

## 五、画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单人全身立像，单画面，非多视图拼接 |
| 背景 | 铁灰纯色 #3A3D44，或按调用方指定的简化暗环境 |
| 姿态 | 可为站立、持械、施法预备等静态姿势 |
| 光线 | 低键布光，单一主光 + 极弱补光，硬边阴影 |
| 一致性 | 与基础形象的面容/肤色/发色/头身比完全一致 |
| 画面比例 | 默认 3:4（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 面容/五官/肤色/发色/头身比必须与基础形象完全一致 |
| R2 | 服饰必须声明势力类型、主色、形制、纹样四项 |
| R3 | 必须声明入魔程度（含"未入魔"）及对应的魔纹面积与眼瞳状态 |
| R4 | 魔纹颜色必须落在 C2 血赤或 C3 幽紫色域 |
| R5 | 布料与金属必须带磨损、撕口或锈蚀描述 |
| R6 | 墨黑必须占画面 50% 以上 |
| R7 | 全身立像必须从头顶到脚底完整入画，严禁裁切 |
| R8 | 必须为单画面单人，不得拼接多视图 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 改变基础形象的面容/五官/肤色/发色/身高比例 |
| X2 | 仙青、金光等正道系灵光色 |
| X3 | 全新无瑕的服饰与法宝 |
| X4 | 暖色光源（血光、火光、魔丹光除外） |
| X5 | 3D 写实渲染 / 照片级真实感 |
| X6 | 西方哥特/吸血鬼/恶魔角等欧美暗黑符号 |
| X7 | 裁切头顶或脚底 |
| X8 | 画面被拼接成多视图/网格/分屏布局 |
| X9 | 开放性创口、断肢、内脏等生理性猎奇内容 |
| X10 | 魔纹面积与入魔程度矛盾 |
