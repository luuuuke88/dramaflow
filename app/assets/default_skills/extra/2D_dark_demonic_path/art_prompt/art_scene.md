# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **暗部即主体** — 墨黑占画面 50% 以上，光只用来切割暗部、勾出必要信息
2. **层次纵深** — 所有场景必须具备前/中/后景，用光条与雾气分层
3. **腐朽至上** — 一切材质带破损、锈蚀、血污、霉斑，禁止全新无瑕
4. **二次元厚涂为锚** — 厚涂笔触与硬边阴影，拒绝 3D 写实与照片质感

## 二、季节与天候映射

| 季节 | 主色调 | 辅色调 | 提示词 |
|---|---|---|---|
| 春 | 病青 + 墨黑 | 惨绿、暗褐 | 瘴气弥漫、腐叶新芽 |
| 夏 | 墨黑 + 血赤 | 铁灰、暗褐 | 闷热无风、血腥味凝滞 |
| 秋 | 暗褐 + 锈金 | 铁灰、灰蓝 | 枯枝萧索、锈色遍地 |
| 冬 | 冷白 + 灰蓝 | 墨黑、血赤 | 雪覆废墟、血迹刺目 |

| 天候 | 视觉表现 | 提示词 |
|---|---|---|
| 阴云 | 厚重压顶、无直射光 | 阴云压顶、全场漫射弱光 |
| 黑雾 | 翻涌有体积、吞噬远景 | 黑雾翻涌、远景被吞没 |
| 血雨 | 暗红雨丝、地面积水泛红 | 血色雨丝、地面泛红积水 |
| 瘴气 | 病青绿色雾层、贴地流动 | 病青瘴气、贴地流动 |
| 雪 | 冷白覆盖、反衬黑与血 | 积雪覆盖、黑白血三色对比 |

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 魔宫/囚牢/祭坛/血池/废弃道观 | 魔道{场景类型} |
| 材质 | 黑石为主，锈铁/朽木/白骨为辅 | 黑石砌筑、锈铁栅栏、朽木梁架、白骨装饰 |
| 色调 | 墨黑主导 + 血赤或惨绿单一光源 | 墨黑主导、单一暖源 |
| 纵深 | 前/中/后景层次，用光条分层 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 石面霉斑/铁锈流痕/血渍干涸可辨 | 霉斑、铁锈流痕、干涸血渍 |
| 光照 | 单一光源（火把/鬼火/魔丹/铁窗漏光） | 火把孤光 / 鬼火惨绿 / 铁窗光条 |
| 镜头感 | 硬边阴影、高对比、暗部有细节不死黑 | 硬边阴影、高对比、暗部保留细节 |
| 瑕疵感 | 墙面剥落、地面积水、蛛网结尘 | 墙面剥落、积水、蛛网积尘 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 魔宫正殿 | 黑石巨柱、高座、垂落黑幡 | 阴森、威压、秩序腐朽 |
| 囚牢 | 锈铁栅栏、锁链、石台、铁窗光条 | 压迫、束缚、绝望 |
| 祭坛 | 环形阵纹、石台、燃烧的暗红符文 | 仪式感、诡谲、不祥 |
| 血池 | 暗红液面、石阶没入、雾气蒸腾 | 粘稠、堕落、诱惑 |
| 废弃道观 | 倾倒神像、断裂匾额、蛛网 | 荒废、讽刺、时间感 |
| 炼傀室 | 悬吊丝线、工作台、零散木偶部件 | 精密、非人、毛骨悚然 |

## 四、室外场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 尸山/枯林/血湖/魔域裂谷/废墟山门 | {场景}，{季节}，{时间} |
| 尺度 | 用废墟与残骸的重复排列体现规模 | 大尺度、重复排列的残骸 |
| 植被 | 枯木/藤蔓/毒蕈/腐叶（须符合季节） | 焦黑枯木、垂落藤蔓、毒蕈 |
| 水体 | 暗红或墨黑，反射被压到最低 | 暗红死水、几无反射 |
| 建筑 | 断壁残垣、倾斜牌坊、坍塌飞檐 | 断壁残垣、倾斜牌坊、坍塌屋顶 |
| 空气感 | 必须有雾或瘴气分层做空气透视 | 雾气分层、空气透视 |
| 光照 | 无直射阳光，天光为漫射弱光或无 | 阴云漫射弱光 / 唯一鬼火光源 |
| 镜头感 | 硬边阴影、高对比、剪影化远景 | 硬边阴影、远景剪影化 |
| 瑕疵感 | 焦痕、风化、血渍、骨骸散落 | 焦黑痕迹、风化剥落、散落骨骸 |

### 室外类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 尸山 | 层叠白骨、残破兵器、乌鸦 | 死寂、规模、麻木 |
| 枯林 | 焦黑树干、垂藤、地面腐叶 | 迷失、压抑、无出路 |
| 血湖 | 暗红湖面、伸出的枯枝、雾 | 粘稠、静止、危险平静 |
| 魔域裂谷 | 深不见底的裂隙、幽紫光自下 | 深渊、诱惑、不可名状 |
| 废墟山门 | 断裂牌坊、倒伏石狮、荒草 | 覆灭、讽刺、时间碾过 |
| 雪原孤行 | 无垠雪面、一行脚印、远处黑点 | 孤绝、寂灭、疲惫 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从最能体现压迫感与空间纵深的角度拍摄。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 能体现压迫感与纵深的代表性角度 | hero shot、oppressive angle |
| 视点高度 | 默认略低于人眼（微仰）以增压迫；尸山与裂谷可俯视 | slightly low angle（默认） |
| 构图 | 前/中/后景层次清晰，暗部占主体 | balanced composition、dark dominant |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓**（散落白骨不算人物） |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 必须包含雾气或瘴气分层做空气透视 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 墨黑必须占画面 50% 以上 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须声明单一光源类型与颜色，且暖光只能来自火、血或魔丹 |
| R7 | 必须包含「硬边阴影 + 高对比」 |
| R8 | 暗部必须保留细节，禁止死黑一片 |
| R9 | 材质必须带破损、锈蚀、血污或霉斑 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 明亮通透的高调画面 / 阳光暖调 |
| X2 | 仙青、金光等正道系灵光色 |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实渲染/照片级真实感 |
| X8 | 材质干净完美、无使用痕迹 |
| X9 | 西方哥特十字架/教堂/吸血鬼符号 |
| X10 | 血腥器官、断肢、内脏等生理性猎奇内容 |
| X11 | 暗部糊成死黑、无任何细节 |
