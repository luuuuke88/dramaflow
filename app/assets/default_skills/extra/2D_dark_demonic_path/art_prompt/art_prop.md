# 道具图像生成 · 约束手册

---

## 一、道具美学原则

1. **形制有据** — 魔道法器形制须能反映其用途与邪性，不做无意义堆砌
2. **腐朽为王** — 锈蚀、血槽、缺口、缠绕物必须清晰可辨
3. **暗器即人格** — 器物的破损方式应能反映主人的性格与经历
4. **二次元厚涂为锚** — 厚涂笔触与硬边阴影，拒绝 3D 写实与照片质感

---

## 二、道具邪性等级

| 等级 | 材质规格 | 魔光 | 纹样密度 | 提示词 |
|---|---|---|---|---|
| 凡器 | 普通铁木、无魔光 | 无 | 无纹 | 普通铁木、素面无纹、无魔光 |
| 染器 | 锈铁、暗玉 | 极淡血赤渗光 | 简单血纹 | 锈铁暗玉、简单血纹、淡血赤渗光 |
| 魔器 | 玄铁带血槽、黑玉 | 明显幽紫魔光 | 密集暗纹 | 玄铁血槽、黑玉、密集暗纹、幽紫魔光 |
| 邪宝 | 骨材、活性金属 | 强魔光 + 黑雾 | 复合魔阵 | 骨材、活性金属、复合魔阵、黑雾缭绕 |
| 魔祖遗物 | 不可名状材质 | 血月色异光 + 空间扭曲 | 活性魔纹（会蠕动） | 材质不可名状、蠕动魔纹、空间扭曲 |

## 三、道具类型速查

| 类型 | 核心形制 | 材质要点 | 氛围词 |
|---|---|---|---|
| 魔剑 | 剑身宽厚带血槽、护手狰狞 | 锈迹沿血槽沉积、刃口有崩缺 | 沉重、贪婪、嗜血 |
| 魔丹 | 暗红球体、表面有裂纹 | 内部有缓慢流动的暗光 | 诱惑、危险、不祥 |
| 骨笛 | 长骨中空、指孔边缘磨圆 | 骨质微黄、有握持包浆 | 阴森、控制、诡异 |
| 血符 | 黄纸暗红朱砂或人皮 | 纸张发脆、血迹渗透背面 | 一次性、代价、禁忌 |
| 锁魂链 | 黑铁细链、末端带钩 | 链节锈死、有暗色沉积 | 束缚、拖拽、绝望 |
| 傀儡丝 | 极细银丝、缠绕成团 | 反光极小、有断头毛刺 | 精密、非人、操控 |
| 毒瓶 | 深色小瓶、蜡封 | 玻璃浑浊、瓶身有指痕 | 隐秘、迅捷、卑劣 |
| 断裂宗徽 | 原为正道信物，被劈开 | 断口新、其余面锈蚀 | 背叛、决裂、过去 |

## 四、材质约束

| 材质 | 表现要求 | 提示词 |
|---|---|---|
| 金属 | 锈蚀沉积、边缘崩缺、暗色氧化 | 金属锈蚀、边缘崩缺、暗色氧化 |
| 黑玉 | 哑光为主、内部微弱幽紫透光 | 黑玉哑光、内部幽紫微透 |
| 骨材 | 表面细孔、微黄、握持处包浆 | 骨质细孔、微黄沉淀、握持包浆 |
| 布/皮 | 发脆、边缘卷曲、暗色渗染 | 材质发脆、边缘卷曲、暗色渗染 |
| 纸 | 纤维发黄、血迹透背 | 纸张发脆泛黄、血迹透背 |
| 活性材质 | 表面缓慢起伏、光泽游移 | 表面缓慢起伏、光泽游移 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从最能体现道具形制与腐朽质感的角度拍摄。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 四分之三侧视为主，能同时展示正面与侧面结构 | three-quarter view |
| 视点高度 | 略高于道具中心，微俯 | slightly above center |
| 构图 | 道具居中，占画面 70%-85% | centered composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面单件道具（成组道具除外，如一束傀儡丝） |
| 人物 | **严禁出现任何人物、手部或人体局部** |
| 背景 | 墨黑近纯色 #121016 或极简暗背景 |
| 光线 | 单一主光偏上前方 45°，弱冷轮廓光勾边，突出材质 |
| 一致性 | 材质/色调/光线与全局风格统一 |
| 画面比例 | 默认 1:1（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明道具邪性等级，并使材质与魔光符合该等级 |
| R2 | 必须声明主体材质及其表现要求 |
| R3 | 必须包含腐朽痕迹（锈蚀/崩缺/血迹沉积/包浆至少一项） |
| R4 | 必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R5 | **严禁出现任何人物、手部或人体局部** |
| R6 | 魔光颜色必须落在 C2 血赤或 C3 幽紫色域 |
| R7 | 必须包含「硬边阴影 + 低键布光」 |
| R8 | 暗部必须保留细节，禁止死黑一片 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 全新无瑕、出厂状态的道具 |
| X2 | 仙青、金光等正道系灵光色 |
| X3 | 3D 写实渲染/照片级真实感 |
| X4 | 出现人物、手部或任何人体局部 |
| X5 | 画面被拼接成多视图/网格/分屏布局 |
| X6 | 西方哥特十字架/吸血鬼道具符号 |
| X7 | 纹样密度与邪性等级矛盾 |
| X8 | 复杂场景背景喧宾夺主 |
| X9 | 器官、断肢等生理性猎奇内容（骨材需为清洁白骨或工艺化处理） |
| X10 | 暗部糊成死黑、无任何细节 |
