# 国漫修仙3D风格说明

本风格专为"国漫修仙三维番剧"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **国漫修仙三维番剧**：以中式修真世界观为背景的三维动画风格，涵盖宗门、洞天福地、渡劫、斗法等题材
- **半写实骨相**：人物面部与体型贴近真实解剖比例，但保留东方审美的理想化处理，非二次元大眼小脸
- **三维渲染技法**：次表面散射皮肤、布料物理解算、体积光与大气散射、灵气粒子系统
- **东方仙侠美术**：云海、飞剑、道袍、符文、法宝、灵植等修真元素的体系化视觉表达
- **大境界感**：开阔的空间尺度、强烈的空气透视、渺小人物对比宏大天地
- **电影级构图**：长焦压缩、浅景深、逆光轮廓、动态张力

## 适用范围

- 修仙/修真题材的 AI 美术生成（角色、场景、道具、分镜等）
- 需要三维番剧质感、灵气特效、宏大世界观的视觉创作
- 国产动画、修真游戏美术、概念设计

## 严禁内容

- 二次元赛璐璐平涂/手绘线稿/漫画分格
- 照片级真人摄影/实拍质感
- 西方魔法/欧式城堡/龙与地下城元素
- 荧光电子色/霓虹赛博/机械科技元素
- 塑料感材质/纯反射镜面/无磨损的全新表面
- 面部僵硬如人偶/表情失真/恐怖谷观感

## 风格体验

在本风格下，您将体验到：

- 角色为半写实三维造型，骨相清晰、发丝根根分明、道袍随风物理飘动
- 场景空间尺度宏大，云海翻涌、山门巍峨，空气透视层次分明
- 法宝与丹炉材质考究，金属有氧化包浆、玉石有内部透光
- 分镜强调体积光、灵气粒子与电影级运镜，境界感与宿命感并重
