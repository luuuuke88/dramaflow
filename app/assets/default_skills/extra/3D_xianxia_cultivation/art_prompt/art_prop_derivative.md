# 道具衍生状态生成 · 约束手册

> 衍生道具 = 在「基础道具」之上改变激活状态、损毁程度、封印状态或品阶跃迁的变体。
> 形制、主体材质、纹样布局**永不改变**，仅改变状态附着层。

---

## 一、衍生原则

1. **形制不可动** — 外形轮廓、比例、结构、纹样布局必须与基础道具完全一致
2. **只改状态** — 灵光、损毁、封印、氧化程度为附加层
3. **痕迹只增** — 磨损与战损不可回退（除非明确设定为"修复/祭炼"）
4. **材质承续** — 次表面散射、金属氧化等质感规则全局继承

---

## 二、激活状态

| 状态 | 表现 | 提示词 |
|---|---|---|
| 沉寂 | 无灵光、纹样暗淡、如凡铁 | 无灵光、纹样暗淡、材质晦暗 |
| 苏醒 | 纹样开始泛光、边缘微亮 | 纹样微光流转、边缘泛亮 |
| 激发 | 灵光明亮、粒子逸散、微微悬浮 | 强灵光、灵气粒子逸散、悬浮微颤 |
| 全力 | 灵光刺目、空间扭曲、周围物体被吹动 | 刺目灵光、空间扭曲、气流外扩 |

> 灵光颜色须与基础道具的品阶色域一致（灵器/法宝：C1 仙青；灵宝/仙器：C5 霞紫）。

---

## 三、损毁状态

| 程度 | 表现 | 提示词 |
|---|---|---|
| 微损 | 刃口崩缺、表面划痕、局部纹样断裂 | 刃口崩缺、表面划痕、纹样局部断裂 |
| 中损 | 主体裂纹贯穿、部件缺失、灵光不稳 | 贯穿裂纹、部件缺失、灵光闪烁不稳 |
| 重损 | 断裂为数段、纹样失效、灵光尽失 | 断裂数段、符文失效、彻底无灵光 |

> 断口必须符合材质力学：金属为韧性撕裂口，玉石为脆性贝壳状断口，木质为纤维撕裂。

---

## 四、封印状态

| 类型 | 表现 | 提示词 |
|---|---|---|
| 符纸封印 | 表面贴附黄纸朱砂符 | 黄纸朱砂符封贴、符纸边角翘起 |
| 锁链封印 | 缠绕玄铁锁链、链身有符文 | 玄铁锁链缠绕、链身符文 |
| 阵法封印 | 悬浮于符阵中央、阵纹发光 | 悬浮符阵中央、阵纹发光、束缚感 |
| 蒙尘封存 | 厚积尘、蛛网、布巾包裹 | 厚积尘埃、蛛网、旧布包裹 |

---

## 五、品阶跃迁

> 仅在剧情明确"祭炼/进阶"时使用。

| 变化 | 允许的改动 | 禁止的改动 |
|---|---|---|
| 材质升华 | 表面质感更致密、内部出现流转光 | 更换主体材质种类 |
| 纹样增生 | 在原有纹样基础上向外延展新符文 | 改变原有纹样布局 |
| 灵光升阶 | 由仙青升为霞紫 | 使用色盘外颜色 |
| 尺寸微调 | ±10% 以内 | 明显改变比例或形制 |

---

## 六、画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面单件道具，与基础道具同机位或近机位 |
| 人物 | **严禁出现任何人物、手部或人体局部** |
| 背景 | 苍黛纯色 #4A5B6B 或极简暗背景 |
| 光线 | 主光上前方 45°，激活状态可叠加道具自发光 |
| 一致性 | 形制/比例/材质/纹样布局与基础道具完全一致 |
| 画面比例 | 默认 1:1（或按调用方设定） |

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 形制/比例/主体材质/纹样布局必须与基础道具完全一致 |
| R2 | 必须声明激活状态（含"沉寂"） |
| R3 | 灵光颜色必须与基础道具品阶色域一致 |
| R4 | 损毁断口必须符合材质力学（金属韧性撕裂/玉石贝壳状断口/木质纤维撕裂） |
| R5 | 磨损痕迹只增不减 |
| R6 | **严禁出现任何人物、手部或人体局部** |
| R7 | 必须为单画面单件道具，与基础道具同机位或近机位 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 改变基础道具的形制/比例/主体材质/纹样布局 |
| X2 | 损毁后材质反而变新、痕迹减少 |
| X3 | 断口不符合材质力学（如玉石出现金属撕裂口） |
| X4 | 荧光电子色灵光或色盘外颜色 |
| X5 | 出现人物、手部或任何人体局部 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 赛璐璐平涂/手绘线稿质感 |
| X8 | 未经剧情设定擅自做品阶跃迁 |
