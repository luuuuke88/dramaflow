# 人物衍生资产生成 · 约束手册

> 衍生资产 = 在「基础形象」之上叠加服化、境界状态、战损、法宝加持等变体。
> 底模的骨相/体型/发色/身高**永不改变**，仅叠加外层。

---

## 一、衍生原则

1. **底模不可动** — 面容骨相、头身比、肤色、发色必须与基础形象完全一致
2. **只做加法** — 服饰、发冠、法宝、光效为叠加层，不得改写人物本体
3. **境界可读** — 服饰规格与灵光强度必须能反映角色当前修为
4. **材质承续** — 次表面散射、布料解算、金属氧化等质感规则全局继承

### 服饰材质约束

| 部位 | 材质 | 提示词 |
|---|---|---|
| 外袍 | 丝麻混纺，垂坠感强 | 布料物理解算、自然垂坠、褶皱真实 |
| 护甲/腕护 | 皮革或轻金属，有磨损 | 皮革磨损、金属氧化包浆 |
| 腰带/绦带 | 编织纹理可辨 | 编织纹理清晰 |
| 发冠 | 玉、木或素银 | 玉质内部透光 / 素银氧化 |
| 靴履 | 布靴或皮靴，鞋底有泥痕 | 鞋底磨损、有使用痕迹 |

## 三、境界状态叠加

| 境界阶段 | 灵光强度 | 视觉表现 | 提示词 |
|---|---|---|---|
| 炼气/筑基 | 无或极弱 | 无外显灵光，气质青涩 | 无灵光外显 |
| 金丹 | 弱 | 体表极淡仙青流光 | 淡仙青流光、微弱灵气环绕 |
| 元婴 | 中 | 灵气粒子环绕，衣袂自动微扬 | 灵气粒子环绕、衣袂微扬 |
| 化神 | 强 | 明显护体罡气，脚下有淡光晕 | 护体罡气、足下光晕、体积光 |
| 渡劫/大乘 | 极强 | 霞紫天光笼罩，空间微扭曲 | 霞紫天光、空间扭曲、强体积光 |

> 灵光只做**叠加**，不得改变人物肤色与服饰本色。

## 四、战损状态

| 程度 | 表现 | 提示词 |
|---|---|---|
| 轻微 | 衣角撕裂、发丝散乱、面有尘土 | 衣角撕裂、发丝散乱、面部尘土 |
| 中度 | 袍身破口、渗血、护甲开裂 | 袍身破口、血迹渗染、护甲开裂 |
| 重度 | 大面积破损、血污、单膝支地 | 大面积破损、血污、力竭姿态 |

> 战损不得改变角色骨相与五官，血污须符合 C8 丹赤色域，禁止鲜艳番茄红。

## 五、画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单人全身立像，单画面，非多视图拼接 |
| 背景 | 雾灰纯色 #9AA5AC，或按调用方指定的简化环境 |
| 姿态 | 可为站立、持械、施法预备等静态姿势 |
| 光线 | 三点布光 + 情绪补光，光影方向与灵光逻辑一致 |
| 一致性 | 与基础形象的骨相/肤色/发色/头身比完全一致 |
| 画面比例 | 默认 3:4（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 骨相/五官/肤色/发色/头身比必须与基础形象完全一致 |
| R2 | 服饰必须声明门派类型、主色、形制、纹样四项 |
| R3 | 必须声明境界灵光强度（含"无灵光外显"） |
| R4 | 布料必须声明「物理解算 + 自然垂坠褶皱」 |
| R5 | 金属与皮革必须带磨损或氧化描述 |
| R6 | 全身立像必须从头顶到脚底完整入画，严禁裁切 |
| R7 | 必须为单画面单人，不得拼接多视图 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 改变基础形象的骨相/五官/肤色/发色/身高比例 |
| X2 | 荧光电子色灵光（必须落在 C1 仙青 / C5 霞紫色域） |
| X3 | 全新无瑕的服饰与法宝（必须有使用痕迹） |
| X4 | 塑料感材质/纯反射镜面 |
| X5 | 二次元赛璐璐平涂质感 |
| X6 | 血污使用鲜艳番茄红或荧光红 |
| X7 | 裁切头顶或脚底 |
| X8 | 画面被拼接成多视图/网格/分屏布局 |
