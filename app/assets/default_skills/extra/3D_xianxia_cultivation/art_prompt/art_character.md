# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **骨相即根基** — 半写实三维骨相是核心锚点，颧骨、下颌、眉弓结构清晰可辨
2. **底模即基础** — 基础素色道袍 + 素颜，后续服化法宝均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **境界气质** — 无妆状态仍需体现修为气度（清冷出尘/沉稳如渊/锋芒毕露）

---

## 二、面容约束

> 不固定五官参数，由角色描述（性别/年龄/性格/境界）驱动 AI 自由生成五官，保证人物间差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 国漫修仙三维番剧、半写实骨相、次表面散射皮肤、体积光 |
| 骨相 | 颧骨/下颌线/眉弓/鼻梁结构必须清晰，禁止二次元扁平脸 |
| 气质 | 必须从角色描述提炼气质关键词（如清冷出尘/沉稳如渊/桀骜锋利），并写入提示词 |
| 表情 | 中性微表情，眼神须有内容，禁止空洞人偶眼 |

## 五、基础发型约束

> 仅定义自然发型，发冠与法器发饰在服化衍生环节叠加。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 墨黑或霜白（霜白仅限设定为高境界/异变角色） | 墨黑长发 / 霜白长发 |
| 发长 | 长发及腰或更长 | 长发及腰 |
| 发质 | 三维发丝解算、根根分明、有自然分组 | 发丝清晰、三维发丝解算 |
| 造型 | 自然披散或简单束发、无发冠 | 长发自然披散、无发饰 |

### 男性

| 项目 | 约束 | 提示词 |

| 发质 | 三维发丝解算、根根分明 | 发丝清晰、三维发丝解算 |

## 六、基础服装约束

> 基础服装为素色道袍，无宗门纹样、无法宝配饰。正式服饰在服化衍生环节叠加。

### 女性基础服装

素色交领道袍，广袖，腰束素带，布料垂坠感明显，无纹样刺绣。

### 男性基础服装

素色交领长袍，腰束素带，布料厚重有垂感，无纹样刺绣。

### 着装统一规则

- 布料必须体现物理解算的自然垂坠与褶皱
- 除面部/手部/颈部外基本覆盖
- 四视图服装款式完全一致
- 基础服装仅为安全打底，焦点在骨相与体态

## 七、四视图设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 头顶至锁骨 | 从头顶到锁骨完整展示，面部占60%+，骨相清晰 | portrait closeup、facial structure |
| 左二 | 正视图 | 正面 0° | 全身立像 | 面对镜头、双臂自然、从头顶到脚底完整展示 | front view、full body |
| 右二 | 侧视图 | 右侧 90° | 全身立像 | 纯侧面轮廓清晰、从头顶到脚底完整展示 | side view、profile、full body |
| 右一 | 后视图 | 后方 180° | 全身立像 | 后脑/背部/发尾/脚部清晰、从头顶到脚底完整展示 | back view、rear view、full body |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 雾灰纯色 #9AA5AC |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂 |
| 全身展示 | 全身立像必须从头顶到脚底完整入画，严禁裁切 |
| 特写展示 | 人像特写必须从头顶到锁骨完整入画，严禁裁切 |
| 表情 | 中性微表情，眼神有内容 |
| 光线 | 三点布光，主光偏上前方 45°，双侧柔和补光，弱轮廓光 |
| 一致性 | 四视图的肤色/体型/发型/骨相/基础服装完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（女性：素色交领道袍广袖；男性：素色交领长袍） |
| R3 | 必须声明「无发冠、无法宝、无配饰」 |
| R4 | 必须指定「雾灰纯色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例（女性默认 160-172cm/7-8头身，男性默认 178-190cm/7-8头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 必须包含「次表面散射」与「三维发丝解算」 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 基础服装以外的任何服装/法宝/配饰/妆容 |
| X2 | 正顶硬光/正底光/荧光色光源 |
| X3 | 塑料感皮肤 / 无血色死白 / 全哑光皮肤 |
| X4 | 复杂场景背景（必须纯色） |
| X5 | 夸张表情/动态姿势/腾空姿态 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
| X9 | 二次元赛璐璐平涂、扁平脸、大眼小脸的二次元比例 |
| X10 | 面部僵硬如人偶、眼神空洞、恐怖谷观感 |
