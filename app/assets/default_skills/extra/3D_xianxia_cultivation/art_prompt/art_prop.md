# 道具图像生成 · 约束手册

---

## 一、道具美学原则

1. **形制有据** — 法宝形制须能反映其用途与品阶，不做无意义堆砌
2. **材质为王** — 金属氧化、玉石透光、木质包浆必须清晰可辨
3. **岁月即价值** — 越高阶的法宝越应有使用痕迹与沉淀感，禁止全新出厂感
4. **三维为锚** — 三维模型渲染质感，拒绝赛璐璐平涂与手绘线稿

---

## 二、道具品阶体系

| 品阶 | 材质规格 | 灵光 | 纹样密度 | 提示词 |
|---|---|---|---|---|
| 凡品 | 普通铁木、无灵光 | 无 | 无纹 | 普通铁木、素面无纹、无灵光 |
| 灵器 | 精铁、青玉 | 极淡仙青流光 | 简单回纹 | 精铁青玉、简单回纹、淡仙青流光 |
| 法宝 | 玄铁、暖玉、鎏金 | 明显仙青灵光 | 密集符文 | 玄铁暖玉、鎏金符文、仙青灵光 |
| 灵宝 | 星辰砂、寒玉 | 强灵光 + 粒子 | 复合符阵 | 星辰砂寒玉、复合符阵、强灵光粒子 |
| 仙器 | 未知材质、内部流转 | 霞紫天光 + 空间扭曲 | 活性符文（会流动） | 材质内部流转、活性符文、霞紫天光 |

## 三、道具类型速查

| 类型 | 核心形制 | 材质要点 | 氛围词 |
|---|---|---|---|
| 飞剑 | 剑身细长、剑格简洁、无繁复护手 | 剑脊有锻打纹、刃口有细微崩口 | 凌厉、轻盈、锋芒 |
| 丹炉 | 三足两耳、炉身厚重、炉盖有孔 | 青铜氧化、炉底火燎焦痕 | 厚重、炽热、古朴 |
| 玉简 | 长方薄片、边缘圆润 | 玉质内部透光、表面有指痕包浆 | 温润、内敛、承载 |
| 符箓 | 黄纸朱砂或兽皮 | 纸张纤维可见、朱砂有笔触厚度 | 一次性、紧迫、灵动 |
| 灵草 | 根茎叶完整、异色 | 叶脉清晰、根部带土 | 生机、稀有、药性 |
| 法印 | 方形或兽钮、印底有阵纹 | 玉石或金属、边角磨圆 | 权威、镇压、秩序 |
| 阵旗 | 旗面绘阵纹、旗杆细长 | 布料磨损起毛、旗杆有握痕 | 布局、协同、战术 |
| 储物袋/戒 | 素面小巧、纹样极简 | 皮革磨损或金属包浆 | 日常、随身、朴素 |

## 四、材质约束

| 材质 | 表现要求 | 提示词 |
|---|---|---|
| 金属 | 表面氧化、局部包浆、边缘磨亮 | 金属氧化、包浆、边缘磨亮 |
| 玉石 | 次表面散射、内部透光、有天然绺裂 | 玉石次表面散射、内部透光、天然绺裂 |
| 木质 | 木纹清晰、握持处包浆变深 | 木纹清晰、握持包浆 |
| 布料 | 纤维可辨、边缘起毛 | 布料纤维、边缘起毛 |
| 纸张 | 纤维纹理、边角磨损泛黄 | 纸张纤维、边角泛黄磨损 |
| 骨/角 | 表面细孔、微黄沉淀 | 骨质细孔、微黄沉淀 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从最能体现道具形制与材质的角度拍摄。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 四分之三侧视为主，能同时展示正面与侧面结构 | three-quarter view |
| 视点高度 | 略高于道具中心，微俯 | slightly above center |
| 构图 | 道具居中，占画面 70%-85% | centered composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面单件道具（成组道具除外，如一套阵旗） |
| 人物 | **严禁出现任何人物、手部或人体局部** |
| 背景 | 苍黛纯色 #4A5B6B 或极简暗背景 |
| 光线 | 主光偏上前方 45°，弱轮廓光勾边，突出材质 |
| 一致性 | 材质/色调/光线与全局风格统一 |
| 画面比例 | 默认 1:1（或按调用方设定） |

{主体材质}，{材质表现要求}，{次要材质},
{纹样类型与密度}，{灵光强度与颜色},

四分之三侧视，微俯视点，道具居中占画面 70%-85%,
{背景描述}，主光上前方45°，弱轮廓光勾边，材质高光准确,
浅景深，材质细节超清晰,
单画面单件道具，画面中无任何人物与手部

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明道具品阶，并使材质与灵光符合该品阶 |
| R2 | 必须声明主体材质及其表现要求 |
| R3 | 必须包含使用痕迹（氧化/包浆/磨损/绺裂至少一项） |
| R4 | 必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R5 | **严禁出现任何人物、手部或人体局部** |
| R6 | 必须包含三维渲染关键词（3D rendered prop） |
| R7 | 玉石类必须声明「次表面散射」与「内部透光」 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 全新无瑕、出厂状态的道具 |
| X2 | 塑料感材质/纯反射镜面 |
| X3 | 荧光电子色灵光 |
| X4 | 出现人物、手部或任何人体局部 |
| X5 | 画面被拼接成多视图/网格/分屏布局 |
| X6 | 赛璐璐平涂/手绘线稿质感 |
| X7 | 西方魔法器物/机械科技元素 |
| X8 | 纹样密度与品阶矛盾（如凡品满身符阵） |
| X9 | 复杂场景背景喧宾夺主 |
