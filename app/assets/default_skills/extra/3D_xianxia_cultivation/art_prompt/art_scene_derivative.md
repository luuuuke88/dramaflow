# 场景衍生资产生成 · 约束手册

> 衍生场景 = 在「基础场景」之上更换时间、天候、季节、战损或灵气状态的变体。
> 空间结构、建筑形制、材质体系**永不改变**，仅改变光照与附着状态。

---

## 一、衍生原则

1. **空间不可动** — 建筑位置、体量、结构、材质必须与基础场景完全一致
2. **只改状态** — 时间/天候/季节/损毁/灵气为附加层
3. **光照重算** — 时间与天候变化后，光源方向、色温、阴影必须整体重算
4. **痕迹累加** — 战损与岁月痕迹只增不减

---

## 二、时间变体

| 时段 | 光源方向 | 色温 | 主色 | 提示词 |
|---|---|---|---|---|
| 拂晓 | 低角度东向 | 5200K 偏冷 | 雾灰 + 淡霞紫 | 拂晓微光、低角度侧光、薄雾未散 |
| 正午 | 高位近顶 | 5800K 中性 | 润白 + 松绿 | 正午高位光、短硬阴影、通透 |
| 黄昏 | 低角度西向 | 3800K 暖 | 鎏金 + 丹赤 | 黄昏斜阳、长投影、金红天光 |
| 入夜 | 月光顶侧 | 7000K 冷 | 墨青 + 仙青 | 冷月光、蓝调暗部、灵石微光 |
| 深夜 | 极弱月光 + 人工光 | 7500K 极冷 | 墨青 + 暖玉点光 | 极弱月光、大面积暗部、灯烛孤光 |

## 三、天候变体

| 天候 | 视觉表现 | 提示词 |
|---|---|---|
| 晴 | 光影硬朗、空气通透 | 晴空、硬朗光影、通透空气 |
| 云海涌动 | 云层翻涌有体积、云隙透光 | 翻涌体积云、云隙光柱 |
| 浓雾 | 能见度骤降、层次压缩 | 浓雾弥漫、能见度低、层次压缩 |
| 灵雨 | 雨丝带微光、地面积水反射 | 灵雨如丝、地面反光、水花溅起 |
| 雷劫 | 霞紫闪电、乌云压顶、瞬时补光 | 紫色天雷、乌云压城、瞬时强补光 |
| 落雪 | 积雪覆盖、光线漫反射 | 积雪覆盖、漫反射柔光、雪粒飘落 |

## 四、灵气状态变体

| 状态 | 表现 | 提示词 |
|---|---|---|
| 灵气枯竭 | 色彩去饱和、灵植枯萎、无光效 | 去饱和、灵植枯萎、无灵光 |
| 灵气平稳 | 基线状态 | 灵气微聚、正常色彩 |
| 灵气充盈 | 空气中可见仙青粒子、灵植茂盛 | 仙青灵气粒子、灵植繁茂 |
| 灵脉暴走 | 空间微扭曲、光线折射异常 | 空间扭曲、光线折射异常、强灵光 |

---

## 五、战损变体

| 程度 | 表现 | 提示词 |
|---|---|---|
| 轻微 | 局部碎石、器物倾倒、尘埃扬起 | 局部碎石、器物倾倒、扬尘 |
| 中度 | 梁柱开裂、墙面剑痕、部分坍塌 | 梁柱开裂、剑痕纵横、局部坍塌 |
| 重度 | 大面积废墟、焦痕、残垣断壁 | 大面积废墟、焦黑痕迹、残垣断壁 |

> 战损须遵循力学逻辑：坍塌方向、碎块堆积、承重结构失效路径必须合理。

---

## 六、画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面主视图，与基础场景同机位或近机位 |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 建筑位置/体量/结构/材质与基础场景完全一致 |
| 光线 | 按时间与天候整体重算，单一光源逻辑 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 建筑位置/体量/结构/材质必须与基础场景完全一致 |
| R2 | 必须声明时间时段并给出对应的光源方向与色温 |
| R3 | 必须声明天候状态 |
| R4 | 必须为「单画面主视图」，与基础场景同机位或近机位 |
| R5 | **严禁出现任何人物** |
| R6 | 战损必须遵循力学逻辑（坍塌方向、堆积、承重失效路径合理） |
| R7 | 岁月与磨损痕迹只增不减 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 改变基础场景的建筑位置/体量/结构/材质 |
| X2 | 时间与光源方向矛盾（如黄昏配高位顶光） |
| X3 | 天候与季节矛盾 |
| X4 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X5 | 画面被拼接成多视图/网格/分屏布局 |
| X6 | 赛璐璐平涂/手绘线稿/二次元背景质感 |
| X7 | 战损后材质反而变新、痕迹减少 |
| X8 | 荧光电子色灵光 |
