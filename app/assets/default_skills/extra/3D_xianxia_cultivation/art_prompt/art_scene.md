# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **境界即空间** — 场景尺度承载世界观等级，山门与洞府的体量感必须拉开
2. **层次纵深** — 所有场景必须具备前/中/后景，并强制空气透视
3. **质感至上** — 岩石/木构/金属/云雾等材质必须有三维体积与磨损
4. **三维为锚** — 一切画面以三维渲染为标准，拒绝赛璐璐平涂与手绘线稿

## 二、季节与天候映射

| 季节 | 主色调 | 辅色调 | 提示词 |
|---|---|---|---|
| 春 | 松绿 + 润白 | 仙青、暖玉 | 灵植抽芽、晨雾未散 |
| 夏 | 松绿 + 仙青 | 雾灰、鎏金 | 浓荫蔽日、山溪湍急 |
| 秋 | 鎏金 + 苍黛 | 丹赤、雾灰 | 层林尽染、天高云淡 |
| 冬 | 润白 + 墨青 | 雾灰、仙青 | 雪覆山门、寒气凝霜 |

| 天候 | 视觉表现 | 提示词 |
|---|---|---|
| 云海 | 翻涌流动、有体积、透光 | 翻涌云海、体积云、云隙透光 |
| 薄雾 | 分层堆积、近浓远淡 | 分层薄雾、空气透视强 |
| 雷劫 | 霞紫闪电、瞬时补光 | 紫色雷电、瞬时强补光、乌云压顶 |
| 灵雨 | 雨丝带微光、地面积水反射 | 灵雨如丝、地面反光 |

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 洞府/丹房/藏经阁/大殿/静室 | 修真{场景类型} |
| 材质 | 山岩为主，木构/玉石/青铜为辅 | 岩壁开凿、木构梁架、玉石台座、青铜器物 |
| 色调 | 苍黛岩体 + 暖玉灯烛 + 仙青灵光 | 冷岩暖光、灵光点缀 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 岩面凿痕/木纹/玉石透光可辨 | 凿痕清晰、木纹可见、玉石内部透光 |
| 光照 | 单一主光源逻辑（洞口天光/灯烛/灵石） | 洞口天光、灯烛暖光、灵石冷光 |
| 镜头感 | 浅景深、体积光可见 | shallow depth of field、体积光 |
| 瑕疵感 | 岩面渗水、木梁积尘、器物氧化 | 渗水痕迹、积尘、青铜氧化 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 洞府静室 | 蒲团、灵石、岩壁、香炉 | 幽静内敛、灵气微聚 |
| 丹房 | 丹炉、药柜、火眼、玉瓶 | 药香氤氲、炉火摇曳 |
| 藏经阁 | 书架、玉简、长梯、天窗 | 幽深浩瀚、尘光斜射 |
| 宗门大殿 | 巨柱、高阶、蒲团列阵、宗旗 | 庄严恢宏、秩序森然 |
| 炼器室 | 锻台、铁砧、淬火池、器胚 | 炽热、金属味、火星四溅 |

## 四、室外场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 山门/悬空殿宇/云海/秘境/药圃/剑冢 | {场景}，{季节}，{时间} |
| 尺度 | 必须体现宏大体量，可用小元素做尺度参照 | 宏大尺度、体量对比 |
| 植被 | 古松/灵竹/灵芝/异色灵植（须符合季节） | 苍劲古松、灵竹成海 |
| 水体 | 瀑布/灵泉/云瀑需有体积与反射 | 飞瀑垂落、水雾弥漫 |
| 建筑 | 飞檐斗拱 + 悬空结构 + 巨型石阶 | 飞檐斗拱、悬空楼阁、千级石阶 |
| 空气感 | 必须有强空气透视，远景明显淡化 | 强空气透视、远山淡化 |
| 光照 | 自然光唯一，高位逆光或侧逆光优先 | 高位逆光、云隙光、体积光 |
| 镜头感 | 长焦压缩或广角开阔，浅景深 | 长焦压缩 / 广角开阔、浅景深 |
| 瑕疵感 | 石阶磨损、瓦片残缺、木构风化 | 石阶磨损、瓦片残缺、风化痕迹 |

### 室外类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 宗门山门 | 巨型牌坊、千级石阶、云雾 | 巍峨、门槛感、仰视压迫 |
| 悬空殿宇 | 浮空平台、锁链、云海 | 超脱、不可思议、失重 |
| 云海之上 | 翻涌云层、露出峰顶、日出 | 开阔、辽远、孤高 |
| 秘境入口 | 裂隙、符文光门、乱石 | 危险、未知、诱惑 |
| 灵药圃 | 分格药田、灵植异色、晨雾 | 生机、清新、井然 |
| 剑冢 | 插满断剑的荒原、残碑 | 苍凉、悲壮、沉寂 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从最能体现场景体量与纵深的角度拍摄。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 能体现场景体量与空间纵深的代表性角度 | hero shot、representative angle |
| 视点高度 | 默认人眼平视；山门/殿宇可仰视，云海可俯视 | eye level（默认）/ low angle / high angle |
| 构图 | 前/中/后景层次清晰，留出尺度参照物 | balanced composition、scale reference |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 必须包含「空气透视」，室外必须为强空气透视 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景体量并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含三维渲染关键词（3D rendered / volumetric light） |
| R7 | 必须包含镜头光学特征（浅景深 / 长焦压缩 / 广角开阔） |
| R8 | 材质必须带自然磨损与岁月痕迹，禁止全新无瑕 |
| R9 | 宏大场景必须留有尺度参照物以体现体量 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（除非剧情需要渡劫/雷罚） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 赛璐璐平涂/手绘线稿/二次元背景质感 |
| X8 | 材质过于干净完美、无使用痕迹（塑料感） |
| X9 | 光照均匀平坦、无体积光、无景深虚化 |
| X10 | 西方魔法/欧式建筑/机械科技元素混入 |
