# 国漫修仙3D约束 · 国漫修仙三维番剧 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：仙青（C1 #7FC8C2）、润白（C2 #F0F4F5）、墨青（C3 #2E4A55）、鎏金（C4 #D8B45A）、霞紫（C5 #8B6FB5）、苍黛（C6 #4A5B6B）、暖玉（C7 #E8D5B7）、丹赤（C8 #C4452F）、松绿（C9 #5E7F5A）、雾灰（C10 #9AA5AC），整体色温偏冷（5600-6500K），饱和度中（45-60%），呈现清冷开阔的仙侠世界基调
- **冷暖叙事对比** — 冷色（仙青 C1、墨青 C3、苍黛 C6）是本风格的默认基调，代表修行、孤高、天地无情；暖色（鎏金 C4、暖玉 C7、丹赤 C8）是稀缺资源，只在人情、宗门温存、生死关头才启用。暖色越少，出现时越有分量
- **冷暖分配策略** — 斗法/渡劫/秘境段落用极冷调（墨青 + 仙青 + 雾灰），禁用暖光；宗门大典/丹房/师徒对谈用鎏金 + 暖玉；魔道与危险信号用丹赤点缀，且面积不超过画面 15%
- **色盘先行原则** — 段落规划需先绑定情绪场景（御剑远行/宗门大典/生死斗法/渡劫天雷/洞府闭关/药圃灵田），再确定主色+辅色与光影方案，避免"剧情对了但境界感不对"
- **饱和度即境界** — 境界越高的段落越应降低饱和度、提高明度对比，用"淡而有力"代替"艳而热闹"。灵气枯竭段落可整体去饱和至 25% 以下
- **禁用色域** — 荧光电子色、霓虹色、机械科技感冷蓝均与本风格不兼容。色相偏移容差 ±10°，饱和度偏移 ±12%，明度偏移 ±15%

## 二、光影方案体系

- **光影即境界** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **体积光为锚** — 所有光影方案必须保留体积光与大气散射，暗部使用墨青或苍黛渗透，禁止纯黑死黑，允许灵气粒子作为额外光源
- **光源角度** — 默认高位逆光或侧逆光（45°-70°），用轮廓光把人物从云雾背景中"剥"出来；正面平光仅用于日常对话

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 云隙天光 | 润白 + 仙青，高位逆光光柱 | 御剑远行、开阔辽远、豁然开朗 |
| B | 殿宇金辉 | 鎏金 + 丹赤 + 苍黛暗部 | 宗门大典、庄严秩序、身份确立 |
| C | 罡气对撞 | 仙青 + 丹赤强对比硬光 | 生死斗法、爆发、危险迫近 |
| D | 紫电天罚 | 霞紫闪电 + 墨青乌云，瞬时补光 | 渡劫、宿命、壮烈牺牲 |
| E | 孤灯洞府 | 苍黛大暗部 + 暖玉单点光 | 洞府闭关、内敛专注、隐忍蛰伏 |
| F | 晨雾灵田 | 松绿 + 暖玉散射柔光 | 药圃日常、生机安宁、短暂喘息 |
| G | 冷月剑冢 | 墨青 + 雾灰，极弱冷月光 | 苍凉悲壮、追忆、沉寂 |

- **冷暖光分配** — 暖光（方案 B、E、F）只给"人情戏"；一切与修行、战斗、天道相关的段落一律冷光
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **半写实骨相为锚** — 国漫修仙的核心：人物面部贴近真实解剖，颧骨/下颌/眉弓结构清晰，禁止二次元大眼小脸与扁平脸
- **次表面散射 + 布料解算** — 皮肤必须通透有血色，道袍必须有物理垂坠与飘动。这两点是"三维番剧"与"廉价建模"的分水岭
- **材质三维化** — 所有服化道必须体现真实物理属性：金属有氧化包浆与环境反射、玉石有内部透光与天然绺裂、木质有握持包浆、布料有纤维与起毛。禁止塑料感与纯反射镜面
- **磨损即年代** — 越是重要的法宝、越是古老的建筑，磨损痕迹越应明显。全新无瑕 = 廉价感
- **三维不等于写实** — 半写实是理想化的三维，比例经过东方审美修饰（修长、清瘦、挺拔），但不追求毛孔级照片真实，避免恐怖谷

## 四、修真场景空间元素

修真世界观特有的场景元素及其视觉叙事功能：

- **云海/云雾/云瀑** — 最重要的空间分隔与尺度参照物，用云层高度暗示境界高低；云隙透光是本风格的标志性光效
- **千级石阶/巨型牌坊/悬空平台** — 制造仰视压迫与"门槛感"，人物在其中越渺小，世界观越宏大
- **飞剑轨迹/护体罡气/灵气粒子** — 修为的可视化语言，强度必须与角色境界严格对应，不可为了好看而随意加强
- **丹炉火光/灵石冷光/符文流转** — 洞府与丹房的主要光源，是暗场景中唯一的暖色来源（方案 E）
- **断剑荒原/残碑/废弃山门** — 承载"前人已逝"的时间厚度，用于闪回与宿命感段落
- **段落间用云海空镜过渡** — 本风格的场景资产在时段/天候上变体丰富，段落衔接建议用云海或远山空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（灵光骤灭、云层压顶、法宝断裂）而非依赖对白解释
- **尺度参照强制** — 所有宏大场景必须留有可辨识的尺度参照物（人影除外，场景图禁人物），如飞鸟、石阶、单株古松

## 五、修真乐器与环境音

修真世界观下的声音元素约束：

### 乐器选择

- **埙** — 苍凉、宿命、追忆段落的核心乐器，最能承载"天地不仁"的空茫感
- **古琴** — 洞府闭关、师徒对谈、开场定调，是本风格的日常底色
- **箫** — 云海独行、孤高出尘段落，与埙搭配可强化苍茫
- **编钟** — 宗门大典、天道显威、境界突破，一击定乾坤，慎用
- **战鼓** — 斗法与渡劫段落的节奏引擎，鼓点密度直接对应战况烈度
- **人声吟诵（无词）** — 渡劫、飞升、天道降临时的终极手段，一部剧不宜超过两次
- 弦乐铺底可增加史诗感，但在洞府/静室段落必须撤走，留出"静"

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 开场/定调 | 古琴独奏 |
| 云海独行/孤高 | 箫 + 埙 + 极弱弦乐 |
| 洞府闭关/内敛 | 古琴独奏，或纯环境音无配乐 |
| 宗门大典/庄严 | 编钟 + 弦乐铺底 |
| 斗法/紧张 | 战鼓 + 低频弦乐 + 打击点缀 |
| 渡劫/宿命 | 人声吟诵 + 编钟 + 全奏 |
| 苍凉/追忆 | 埙独奏 |
| 药圃/喘息 | 竹笛 + 轻铃 |

### 修真环境音

- **典型环境音层次** — 风过云海 / 剑鸣清越 / 丹炉沸响 / 灵泉滴落 / 山风穿谷 / 道袍猎猎 / 石阶回声 / 雷声滚过云层 / 灵植拔节的细响
- **每场戏标注 1-2 个核心环境音**。修真世界的"静"极重要：洞府与剑冢段落应大胆使用近乎无声，只留一两个细微环境音
